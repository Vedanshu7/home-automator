descriptionLong: home-automator pairs an Android app with Arduino firmware to remotely control 4 relay outputs — lights, fans, AC, and similar appliances — over a local WiFi network. Commands travel over TCP sockets via an ESP8266/ESP-01 WiFi module, so control works entirely on the local network with no cloud service in the loop. A DS3231 real-time clock module drives scheduled on/off timers, and the app gets real-time status feedback from the hardware.
